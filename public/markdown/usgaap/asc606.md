# Revenue from Contracts with Customers

Governs revenue recognition from contracts with customers using the five-step model, converged with IFRS 15.

ASC 606 establishes the core principle for revenue recognition from contracts with customers, applying the five-step model of identifying the contract, performance obligations, transaction price, allocation, and recognition when or as performance obligations are satisfied.
