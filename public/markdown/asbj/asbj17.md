# Accounting Standard for Disclosures about Segments of an Enterprise

Accounting Standard for Disclosures about Segments of an Enterprise is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for disclosures about segments of an enterprise.
