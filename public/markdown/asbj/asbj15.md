# Accounting Standard for Construction Contracts

Accounting Standard for Construction Contracts is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for construction contracts.
