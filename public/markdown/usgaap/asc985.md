# ASC 985 – Software

Governs costs of software to be sold or marketed and internal-use software, distinguishing external-use from internal-use capitalization criteria.

ASC 985 covers software revenue recognition now under ASC 606, capitalization of costs for software to be sold externally, and costs of internal-use software cross-referenced to ASC 350-40. It keyly diverges from IAS 38's unified criteria through its bifurcated US GAAP frameworks for external-use and internal-use software.

## Notice

**warning:** Divergence from IAS 38

ASC 985's bifurcated frameworks for external-use and internal-use software diverge from IAS 38's single set of criteria for an intangible asset. This creates different capitalization boundaries under US GAAP versus IFRS.
