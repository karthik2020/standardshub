# Accounting Standard for Disclosures about Fair Value of Investment and Rental Property

Accounting Standard for Disclosures about Fair Value of Investment and Rental Property is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for disclosures about fair value of investment and rental property.
