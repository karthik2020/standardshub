# Accounting Standard for Share-based Payment

Accounting Standard for Share-based Payment is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for share-based payment.
