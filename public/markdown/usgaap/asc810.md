# Consolidation

Governs consolidation principles using the voting interest entity and variable interest entity models to determine when one entity controls another.

ASC 810 establishes the consolidation model for entities under common control, using both the Voting Interest Entity (VOE) model and the Variable Interest Entity (VIE) model. It determines when one entity must consolidate another, addressing noncontrolling interest presentation, changes in ownership, and loss of control.
