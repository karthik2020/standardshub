# Customer's Accounting for Cloud Computing Arrangements

Customer's Accounting for Cloud Computing Arrangements is part of the Accounting Standards for Private Enterprises (ASPE).

This standard is part of the ASPE framework issued by the Canadian Accounting Standards Board. It provides guidance on customer's accounting for cloud computing arrangements.
