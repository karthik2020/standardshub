# Revenue Recognition

Legacy revenue recognition Topic, largely superseded by ASC 606 for virtually all transactions; retained as a historical placeholder in the Codification.

ASC 605 governed revenue recognition before the 2014 joint FASB/IASB project replaced it with ASC 606. It consists of industry-specific guidance that has been superseded for essentially all transactions.

**Issued:** 1999-01

**Latest Amendment:** 2016-03

**Effective:** 1999-01-01

## Notice

**warning:** Superseded

ASC 606 now governs virtually all revenue recognition; ASC 605 retains almost no independent substantive content.
