# Financial Instruments–Credit Losses

Introduces the current expected credit loss (CECL) model for financial instruments, requiring forward-looking lifetime expected credit loss recognition at origination.

ASC 326 introduces the current expected credit loss (CECL) model for financial instruments measured at amortised cost, available-for-sale debt securities, and off-balance-sheet credit exposures.
