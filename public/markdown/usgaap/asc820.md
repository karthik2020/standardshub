# Fair Value Measurement

Defines fair value, establishes a framework for measuring fair value, and requires disclosures about fair value measurements.

ASC 820 provides a single definition of fair value and a consistent framework for measuring fair value across US GAAP. It establishes a three-level fair value hierarchy (Level 1, 2, and 3 inputs) and requires extensive disclosures about fair value measurements, including the use of significant unobservable inputs.

## Notice

**info:** Converged with IFRS 13

ASC 820 and IFRS 13 are substantially converged. Both frameworks use the same fair value definition, the same three-level hierarchy, and the same disclosure approach, ensuring consistent fair value measurement globally.
