# Accounting Standard for Current Income Taxes

Accounting Standard for Current Income Taxes is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for current income taxes.
