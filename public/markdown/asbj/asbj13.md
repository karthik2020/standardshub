# Accounting Standard for Lease Transactions

Accounting Standard for Lease Transactions is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for lease transactions.
