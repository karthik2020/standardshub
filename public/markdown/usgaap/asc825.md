# Financial Instruments

Provides guidance on the classification, measurement, and disclosure of financial instruments.

ASC 825 addresses the classification and measurement of financial instruments, including the fair value option for certain financial instruments that would otherwise not be measured at fair value. It also provides disclosure requirements for all entities with financial instruments.

**Issued:** 2010-04

**Latest Amendment:** 2016-01

## Notice

**warning:** Key IFRS 9 Divergence

ASC 825's classification and measurement model differs significantly from IFRS 9. IFRS 9 classifies financial assets based on a single SPPI test into amortised cost or FVTPL; ASC 825 retains a more complex, category-based classification model with the fair value option.
