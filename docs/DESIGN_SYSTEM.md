# Purpose

The Design System defines the visual language of StandardsHub.

It provides a consistent set of design foundations used across every page and component.

The design system is derived from the Reference Guide visual language to ensure consistency between the website and educational content.

## Design Philosophy

The interface should never compete with the content.

Reading always takes priority.

The visual language should be:

- Calm
- Professional
- Consistent
- Familiar
- Accessible
