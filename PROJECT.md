# StandardsHub

## Project

StandardsHub is a free educational website for IAS, IFRS and Ind AS standards.

Goals:

- Clean, distraction-free reading
- SEO-friendly individual pages
- Fast loading
- Mobile-first
- Easy maintenance
- Built with Astro

---

# Tech Stack

- Astro
- TypeScript
- CSS
- JSON data

---

# Coding Standards

## CSS

- Single `site.css`
- Use CSS variables
- Avoid hardcoded colours
- Prefer semantic variables
- Mobile-first
- No inline styles

## Components

- Keep components reusable
- Keep pages clean
- Prefer data-driven rendering

---

# Git

# Important Rules

Never redesign working UI without reason.

Keep the visual style consistent.

Prefer maintainability over clever code.

When refactoring, preserve behaviour.
