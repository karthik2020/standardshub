# Accounting Standard for Interim Financial Reporting

Accounting Standard for Interim Financial Reporting is part of the Japan GAAP framework.

This standard is part of the Japan GAAP framework issued by the Accounting Standards Board of Japan (ASBJ). It provides guidance on accounting standard for interim financial reporting.
