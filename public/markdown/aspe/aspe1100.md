# Generally Accepted Accounting Principles

Generally Accepted Accounting Principles is part of the Accounting Standards for Private Enterprises (ASPE).

This standard is part of the ASPE framework issued by the Canadian Accounting Standards Board. It provides guidance on generally accepted accounting principles.
